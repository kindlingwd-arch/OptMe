# OptMe · 影游剪辑台

用剪辑软件的方式做互动影游（互动电影游戏）：**剧本就是剪辑表**，画面、配音、选择都在一条时间线上；素材拖进去就能替换，改完一键导出可以玩的游戏包。

v0.5 起内置了从参考图到成片的整套优化流程，v0.6 把它延伸到视频和声音：**剧本 → ⓪ 参考 → ① 提示词 → ② 图片 → ③ 草稿 → ④ 成片 → ⑤ 台词**，以及只改框里内容的「框选修图」和角色声音复刻。

## 功能

- **故事板模式**：一句台词一张分镜图，先把剧情和画面定下来；拖图替换，一键给缺图的句子出图、整场检查并自动修。
- **视频模式**：场景视频、插入镜头、剪辑入点出点、视频原声。
- **多轨时间线**：画面、台词配音、字幕卡、事件、音乐、环境声；撤销重做；内嵌真实游戏预览；右键写审阅意见、静音。
- **审阅（瀑布流，一张张往下刷，全键盘操作；各页之间跳转停在同一个镜头上）**
  - 剧本：自动查走不到的场景、死路、选项指错、线索拿不到、空台词；剧本改了提示下游要复查。
  - ⓪ 参考：图片参考图登记表（名称、类型、描述、关键词），改描述后 AI 重新生成；**声音音色**：登记角色参考录音，复刻成 MiniMax 音色，生成试听。
  - ① 提示词：显示实际发给出图模型的完整提示词；自动检查字段矛盾、左舵方向、缺参考图等；相邻镜头衔接检查；出图前没审过会提醒。
  - ② 图片：通过 / 有问题（可让 AI 按意见改）/ 修图 / 重画 / 换成之前的候选 / 本地替换；图换了自动回到待审。
  - ③ 草稿：AI 写视频提示词、按剧本算时长、免费的代码草稿、AI 尾帧、2.5D 预演、本地模型草稿、手绘动作，先在游戏里过一遍再花钱。
  - ④ 成片：选模型生成视频（海螺 / H3，显示费用），AI 质检不通过自动重拍；候选对比、本地视频替换、剪辑点、配音和原声。
  - ⑤ 台词：按角色核对每句台词的配音（齐全 / 缺失 / 改字待更新），用复刻音色补配音。
- **框选修图**：在图上框出（或套索圈出）要改的地方写一句话。「只改样子」时框外像素一个不变；「要加东西或改形状」时整张交给 AI，并报告框外变化有多大。
- 任何图片双击放大。

## 目录

```
├─ main.js / preload.js / core.js     Electron 主进程（文件读写、IPC、跑 Python 任务）
├─ voice-*.js / voice_clone_worker.py 声音参考登记和 MiniMax 声音复刻
├─ renderer/        界面（app.js 主体 + 按功能拆出的模块）
├─ storyboard/      剪辑台调用的 Python 工具（出图、质检、修图、参考图生成）
├─ docs/            设计与使用、架构与数据约定、制作流程
└─ skills/yingyou-flow/   让 Claude / Codex 按同一套流程工作的 skill
```

## 运行

剪辑台本体：

```bash
npm install
npm start            # 开发运行
npm run dist:win     # 打 Windows 包（dist/ 下的 zip，解压后双击 YingyouStudio.exe）
```

打开项目时选**游戏文件夹**（里面有带 `const N=` 剧本数据的 `index.html`）。剪辑台约定的目录结构：

```
<项目根目录>/
├─ <游戏文件夹>/        index.html、img/、vid/、vo/ ……（剪辑台的工作数据在 _studio/）
├─ storyboard/         把本仓库的 storyboard/ 放这里，再加上 shotlist.json（分镜表 + 统一设定）
├─ autofix/            视频工具和 video_shots.json（视频分镜表）——目前不在仓库里，见下
└─ refs/               参考图 + refs.json 登记表；声音参考 voice_refs.json + voices/
```

Python 工具（AI 出图、修图、参考图生成、视频、声音复刻）：

```bash
pip install -r storyboard/requirements.txt
```

- 环境变量：
  - `GEMINI_API_KEY`：出图、质检、修图、视频提示词和质检（受限地区需要代理）。
  - `MINIMAX_API_KEY`：视频生成、声音复刻、试听和台词配音。
  - 可选：`YINGYOU_PYTHON`（指定 python.exe）、`AUTOFIX_BUDGET`（视频生成预算，元，默认 20）。
- 剪辑台按顺序找 Python：环境变量 `YINGYOU_PYTHON` → `%USERPROFILE%\anaconda3\python.exe` → `python`。
- 也可以单独双击 `storyboard/run_*.bat`；`run_fix_box.bat` 是框选修图的独立网页版。
- **目前缺的脚本**：衔接检查（`continuity.py`）、手绘构图（`sketch_ai.py`）和整个 `autofix/`（③ 草稿、④ 成片用的视频脚本）还没放进仓库，从仓库安装时这些功能会报「没找到 …」。详见架构文档。
