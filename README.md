# OptMe · 影游剪辑台

用剪辑软件的方式做互动影游（互动电影游戏）：**剧本就是剪辑表**，画面、配音、选择都在一条时间线上；素材拖进去就能替换，改完一键导出可以玩的游戏包。

v0.5 起内置了从参考图到成片的整套优化流程：**⓪ 参考图审阅 → ① 提示词审阅 → ② 图片审阅**，以及只改框里内容的「框选修图」。

## 功能

- **故事板模式**：一句台词一张分镜图，先把剧情和画面定下来；拖图替换，一键给缺图的句子出图、整场检查并自动修。
- **视频模式**：场景视频、插入镜头、剪辑入点出点、视频原声。
- **多轨时间线**：画面、台词配音、字幕卡、事件、音乐、环境声；撤销重做；内嵌真实游戏预览。
- **审阅（瀑布流，一张张往下刷，全键盘操作）**
  - ⓪ 参考图：参考图登记表（名称、类型、描述、关键词），对照统一设定看图，改描述后 AI 重新生成，换本地图片，新增参考图（常见道具预填描述）。
  - ① 提示词：显示实际发给出图模型的完整提示词；自动检查字段矛盾、左舵方向、缺参考图、备注里的画面要求等；出图前没审过会提醒。
  - ② 图片：通过 / 有问题（可让 AI 按意见改）/ 修图 / 重画 / 换成之前的候选；图换了自动回到待审。
- **框选修图**：在图上框出要改的地方写一句话。「只改样子」时框外像素一个不变；「要加东西或改形状」时整张交给 AI，并报告框外变化有多大。
- 任何图片双击放大。

## 目录

```
├─ main.js / preload.js / core.js / renderer/   Electron 桌面程序（剪辑台本体）
├─ storyboard/      剪辑台调用的 Python 工具（出图、质检、修图、参考图生成）
├─ docs/            设计与使用说明、制作流程
└─ skills/yingyou-flow/   让 Claude / Codex 按同一套流程工作的 skill
```

## 运行

剪辑台本体：

```bash
npm install
npm start            # 开发运行
npm run dist:win     # 打 Windows 包（dist/ 下的 zip，解压后双击 YingyouStudio.exe）
```

打开项目时选**游戏文件夹**（里面有带 `const N=` 剧本数据的 `index.html`）。剪辑台约定的目录结构：

```
<项目根目录>/
├─ <游戏文件夹>/        index.html、img/、vid/、audio/ ……（剪辑台的工作数据在 _studio/）
├─ storyboard/         把本仓库的 storyboard/ 放这里，再加上 shotlist.json（分镜表 + 统一设定）
└─ refs/               参考图 + refs.json 登记表（第一次打开时按已有图片自动建）
```

Python 工具（AI 出图、修图、参考图生成）：

```bash
pip install -r storyboard/requirements.txt
```

- 需要环境变量 `GEMINI_API_KEY`（出图模型在受限地区需要代理）。
- 剪辑台按顺序找 Python：环境变量 `YINGYOU_PYTHON` → `%USERPROFILE%\anaconda3\python.exe` → `python`。
- 也可以单独双击 `storyboard/run_*.bat`；`run_fix_box.bat` 是框选修图的独立网页版。
