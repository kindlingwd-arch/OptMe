# 影游剪辑台：设计与使用

## 目的
互动影游由镜头、配音、音乐和选择组成，用剪辑软件的方式调试比用浏览器调试更直观。剪辑台把游戏剧本（index.html 里的 `const N={...}`）当成剪辑表：每个场景是一条多轨时间线，不满意的画面或声音直接拖进去替换，改完一键导出可以玩的游戏包。

## 两种工作模式（v0.3，2026-10-30）
按「图片优先」流程，剪辑台分成两种模式，在左上角切换（会记住上次的选择）：

**故事板模式（默认）**：先把剧情和画面定下来，每句台词对应一张静态分镜图。
- 中间默认显示故事板网格，每张卡片是一句台词，显示对应的分镜图、序号、台词、景别和构图。
  - 卡片标签：✓ 通过质检 / ⚠ 需人看 / 人工确认 / 沿用插图 / 自选图 / 沿用场景图（这一句还没有自己的图）。
  - 鼠标停在卡片上可以看到上次质检发现的问题。
  - 单击：选中这一句；双击：切到「预览」从这一句开始玩。
  - 拖图片到卡片上：直接换成这一句的分镜图。
- 顶部是本场的进度条，还有两个按钮：
  - 「给缺图的句子出图」：调用 `storyboard\batch.py`。
  - 「整场检查并自动修」：调用 `storyboard\refine.py`，只处理还没通过的图。
- 右边面板（选中一句台词时）：
  - 分镜画面：可以换图、在文件夹中显示、不用分镜图（改为沿用场景图）。
  - AI 按钮：
    - 框选修图…：打开「审图 · 框选修图」窗口（见下一节），框出要改的地方，只改框里。
    - AI 按意见修改…：写一句修改意见，AI 在整张图上改（可能顺手改动别处，局部小问题优先用框选修图）；可以勾选「没通过质检也换进游戏」。
    - AI 检查并自动修。
    - 重画这一张。
    - 不用分镜图。
    - 这张没问题，标记人工确认：质检判没通过、但人看过觉得可以时用（只在没通过的图上出现）。
  - 上次质检发现的问题（附分数）。
  - 分镜要求，这里改的内容直接保存到 `storyboard\shotlist.json`，下次出图和质检都按这个来，每次修改前自动备份到 `storyboard\out\backup\`：
    - 景别；
    - 画面里有谁；
    - 构图（按画面方向写）；
    - 画面描述；
    - 参考图（勾选，最多 5 张）。
  - 分镜表里还没有的台词，点「加进分镜表」或直接点 AI 按钮会自动建一条。
- 时间线的「画面 · 分镜」轨，每句一块，显示分镜图；没有自己的图时显示虚化的场景图，并标注「沿用场景图」。
- 出图任务在右下角的任务栏里显示实时日志，可以停止。任务完成后，素材、分镜状态和预览会自动刷新。任务开始前如有未保存的修改，会先自动保存。
- 素材检查只查分镜图相关的问题，不提示缺视频。

**视频模式**：画面定下来以后再做动态镜头，和 v0.2 一样，包括场景视频、插入镜头、剪辑入点和出点、视频原声。

## 审阅（v0.4，2026-10-31）
三道关，按顺序：**⓪ 参考图审阅** → **① 提示词审阅**（出图前）→ **② 图片审阅**（出图后）。参考图是源头：参考图不对，后面全跟着错；提示词提到参考图里没有的东西（钞票、BP机、保险单……），模型只能凭空画。很多图画错，根子在提示词本身有问题（字段之间互相矛盾、关键要求写在不发给模型的备注里、参考图缺了该有的角色或道具），先审参考图和提示词再出图，比出了图再修省得多。
- 入口：顶栏「审阅」（数字是「参考图待审 · 提示词待审 · 图片待审」）；故事板顶部「审阅本场」；菜单「视图 → 审阅分镜图」，快捷键 Ctrl+Shift+A。审阅页左上角切换 ⓪ / ① / ②，每个上面有待审数（会记住上次的选择）。
- 都是全屏瀑布流，一句一张卡片；顶部切换范围（本场 / 全部场景）和筛选（待审 / 有问题 / 全部），带进度条。
- 审阅结果存在 `storyboard\out\review.json`（不和出图脚本抢着写 state.json）。
- 剪辑台里任何一张图（审阅页、修图对话框、新增参考图、右边面板）都可以**双击放大**，放大后 ← → 翻看同一张卡片里的其他图，Esc 或点空白处关闭。能单击增减的缩略图（参考图、生成时一起参考）单击会稍等约 0.25 秒再生效，所以双击不会误触增减。素材库和时间线保留原来的双击（预览 / 从这句开始播），修图窗口的大图不放大（要在上面画框）。

### ⓪ 参考图审阅
- 参考图登记表：`moban_art\refs\refs.json`，每张参考图记名称、类型（人物 / 道具 / 场景）、生成描述、关键词（提示词里出现这些词时应该附上它）、生成时一起参考的其他参考图。第一次打开时按 `refs\` 里已有的图自动建登记，描述取自原来的 `ref_prompts\<id>.txt`。
- 每张卡片：左边大图（双击放大）和「生成时一起参考」；右边是名称、待审状态、几个镜头在用、「统一设定里的写法」（对照看图对不对）、「提示词里提到它却没附上的镜头」（可以一键全部附上），以及可直接修改的名称、类型、关键词、描述。
- 操作：A 参考图没问题；R 按描述重新生成（调用 `storyboard\ref_tool.py`，Gemini 出图，约 $0.14）；换成本地图片；看用到它的镜头（跳到提示词审阅）。重新生成或换图后，原图挪到 `refs\_old\`，不会丢；参考图换了就自动回到「待审」；用到它的镜头要重画才会用上新图。
- 新增参考图：审阅页顶部「＋ 新增参考图」，或提示词卡片参考图一栏最后的「＋ 新增」，或自动检查里的「＋ 新增参考图」按钮（名称、文件名、关键词、描述按常见道具预填：第四套人民币、BP机、财产保险单、白信封、车载收音机、警车、手电筒、箱子里的金货）。可以 AI 生成，也可以导入本地图片；从提示词卡片打开时可以同时附到这个镜头。
- 2026-10-31 用真实的 40 条跑：参考图库里没有、但提示词提到了的有 8 种（收音机 3 个镜头、钞票 1、保险单 4、BP机 2、警车 1、手电 5、信封 2、金光 1）；已有参考图但没附上的有 5 张（客运站 2、车内 1、黑皮箱 2、林间公路 1、出租车 4）。
- 发现：统一设定里写的是「红色夏利出租车」，没写两厢；原来生成出租车参考图的描述里写的是 hatchback（两厢）。建议统一设定补上「五门两厢（掀背）」。

### ① 提示词审阅
- 每张卡片：左边是现在的成图、构图图、俯视位置图和参考图（参考图单击增减，最多 5 张；任何图双击放大，放大后 ← → 翻看本卡的其他图，Esc 关闭）；右边是台词、自动检查结果、可直接修改的分镜字段（景别、场景、画面里、构图、画面描述、备注），改完点别处自动保存到 `shotlist.json`（自动备份）。
- 「实际发给模型的完整提示词」可以展开看，拼法和 `storyboard\batch.py` 的 `prompt()` 逐字一致（两边各有注释提醒同步修改）。
- 自动检查（出图前就能挑出来的常见问题）：
  - 构图或画面描述里出现的人，「画面里」没写（机位、视线方向里提到的不算；只露手、背影这类局部单独提醒）；
  - 从后座往前拍，「画面里」却没有司机；
  - 左舵方向写反（从车里往前看司机应在画面左，从车头前方往里看应在右）；
  - 机位朝后，但统一设定里有挡风玻璃下的红穗子；
  - 写了「后备箱」（参考图的夏利是五门两厢车）；
  - 「远离 / 那边 / 旁边」这类容易理解偏的方向词；
  - 要求画面上的字清楚，和「画面里不要任何文字」冲突；
  - 台词说指甲，提示词却写戴着手套；
  - 备注里像是有画面要求（备注不会发给模型）；
  - 参考图超过 5 张，或缺了画面里的角色；
  - 提到了登记表里某张参考图的关键词却没附上（旁边有「附上」按钮）；提到了参考图库里根本没有的东西（旁边有「＋ 新增参考图」按钮）。「没有警车」「看不到后视镜」这类否定说法不算提到。
  - 2026-10-31 用真实的 40 条跑：6 处矛盾、24 条提醒，和人工审的结论一致。
- 操作：A 提示词没问题（自动跳下一条）；R 按这条出图 / 重画；↑ ↓ 翻页。提示词、参考图或构图图任何一样改了，就自动回到「待审」。
- 出图前提醒：任何地方点出图 / 重画（故事板、右边面板、审阅页），如果有还没审过的提示词，会先弹窗提醒，并标出其中自动检查发现矛盾的镜头；可以选「先去审提示词」「照样出图」或取消。

### ② 图片审阅
- 每张卡片：左边大图，右边是场景和第几句、台词、AI 质检结果、分镜要求、AI 质检发现的问题、审阅意见、其他候选。
- 操作（键盘可以不碰鼠标）：
  - ↑ ↓（或 K / J）：上一张 / 下一张；
  - A 通过：记为人工通过，自动跳到下一张；
  - X 有问题：写一句哪里不对，「只记下」或「记下并让 AI 按意见修改」（调用 refine.py 的人工意见模式）；
  - E 修图：打开框选修图窗口；
  - R 重画：按分镜表整张重画（batch.py）；
  - 点「其他候选」的缩略图可以放大看之前几次出的图，满意就「用这张」换进游戏；
  - 双击大图全屏放大；
  - Esc 关闭。
- 「待审」包括 AI 质检通过的图，人都要过一遍；在修图窗口里采用或标记人工确认过的，算已通过。
- 每条记下审阅时游戏里那张图的修改时间，图被换掉（重画、修图、拖图替换）就自动回到「待审」。
- 审阅页开着时，按键不会传给后面的剪辑台（不会误删台词）。

## 审图 · 框选修图（v0.4，2026-10-31）
细节问题（钞票颜色、车顶灯上的字、道具样式）用「改提示词、整张重画」效率低，而且会把画对的地方改坏。框选修图只改框出来的地方。构图问题（谁在哪、朝哪、机位）仍然用构图草图解决，见 `claude/末班客_图片优先流程与分镜表.md`。
- 入口（三个，都在故事板模式下）：
  - 鼠标停在故事板卡片上，右上角出现「✎ 修图」；
  - 选中一句台词，右边面板顶部的「✎ 审图 · 框选修图…」；
  - 菜单「编辑 → 审图 · 框选修图」，快捷键 Ctrl+Shift+F。
- 更新程序文件后要完全关掉剪辑台再打开（或菜单「视图 → 重新加载界面」），否则还是旧界面。
- 窗口左边是这一句当前的分镜图（游戏里的 16:9 画面），右边是质检发现的问题、分镜要求和修改栏。
- 用法：
  1. 在图上按住鼠标拖出方框，右边写一句怎么改；可以框好几处。
  2. 选修改方式（见下），点「修改框里的内容」，约 30～60 秒（右下角任务栏有日志）。
  3. 用「修改前 / 修改后」切换对比，然后三选一：采用这张、换进游戏；在这张基础上继续改；不要、回到修改前。
  4. 不需要改、只是人看过觉得可以：点「这张没问题，标记人工确认」。
- 两种修改方式（按会不会改变形状来选）：
  - **只改样子，形状不变**（patch）：换颜色、盖掉字、换道具花纹。只把框附近一块裁下来发给 AI（红框画在框外侧），改完只取回框里的像素，边缘羽化贴回原图，框外一个像素不变（用故意捣乱的假 AI 测过：框外改变 0 像素）。每个框调用一次 AI。
  - **要加东西或改形状**（whole）：箱子里加金子、给人戴上帽子。新东西可能长出框外、要有影子和反光，硬贴回会有接缝，所以整张交给 AI：发两张图——干净原图（让 AI 改）和画了编号红框的位置图（只指位置），用 AI 改完的整张图。因为要改的那张图上本来就没有红框，结果里不会残留红线。所有框一次调用。改完会报告「框外变化」大小（很小 / 有一些 / 较大），并检查有没有疑似残留红线，供对比时参考。
- 背后调用 `storyboard\fix_box.py`：
  - `python fix_box.py edit <镜头> <base64(JSON)>`：JSON 里 `mode` 是 `patch` 或 `whole`，框用 0～1 的比例坐标，相对 16:9 画面；
  - `python fix_box.py accept <镜头> <结果文件>`：换进游戏，分镜状态记为「人工确认」（manual）；
  - `python fix_box.py approve <镜头>`：不改图，只标记人工确认；
  - 不带参数运行（或双击 `storyboard\run_fix_box.bat`）是独立的网页版，功能相同。
- 修改结果、每次发给 AI 的局部图（patch）和位置图（whole）都在 `storyboard\out\fix\`；采用前的原图保留在 `storyboard\out\` 里。
- 每次调用约 $0.14，计入 `storyboard\out\batch\state.json` 的累计费用。需要 `GEMINI_API_KEY` 和代理。
- 状态为「人工确认」的镜头，`run_batch.bat` 重跑时会跳过（2026-10-31 起），`refine.py` 默认也不处理。

### 数据约定
- 每句的分镜图存放在 `moban_game\img\l\<场景>_<两位行号>.jpg`。
- 剧本里的写法是 `["你","台词",{"img":"l/ride_00"}]`；游戏里还有一份 `LIMG` 登记表，作为兼容。
- 剪辑台打开项目时，会把已登记的图，或者分镜表里有、图片文件也存在的图，钉到对应的台词上。这样以后插入或移动台词，图也不会对错。
- 分镜工作区固定在游戏文件夹旁边的 `storyboard\`，参考图在 `moban_art\refs\`。
- Python：依次找环境变量 `YINGYOU_PYTHON`、`%USERPROFILE%\anaconda3\python.exe`、`python`。出图需要 `GEMINI_API_KEY` 和代理。

## 桌面版界面
- 位置：`Desktop\moban_art\影游剪辑台\YingyouStudio.exe`，双击就能运行，不用安装。当前程序文件（v0.4）在 `resources\app\`；v0.3 备份在 `影游剪辑台\backup_1031\`，更早的在 `backup_1030\`。
- 欢迎页：打开项目文件夹（有 index.html 的游戏文件夹，例如 `moban_art\moban_game`），也可以从「最近的项目」里打开。
- 顶栏：模式切换、素材检查（带问题数）、导出剪辑表、保存、导出游戏。
- 左边是素材库，分 5 页：
  - 场景：按幕分组的缩略图卡片，带类型、时长和状态点。
  - 媒体：关键帧、视频，还有导入的素材箱。
  - 音频：配音、音乐、音效、环境声，可以试听。
  - 线索：直接改文字，能看到在哪些场景给出。
  - 故事图。
- 中间：「故事板 / 预览」两个页签。预览是内嵌的真实游戏，可以从本场开头播放，也可以上一句、下一句。
- 右边是属性面板，内容随选中的东西变：场景、台词、镜头、字幕卡、选项、密码锁、结局、音乐 / 环境声。素材框可以直接拖文件进去替换。
- 底部是多轨时间线：
  - 轨道：画面 · 分镜（故事板模式），或者画面加插入镜头（视频模式）；台词 · 配音；字幕卡；事件；音乐；环境声。
  - 拖放：把素材库里的素材，或电脑里的文件，拖到块上即可替换。单击块看属性，双击块从那一句开始预览。
- 快捷键：
  - Ctrl+S 保存
  - Ctrl+Z / Ctrl+Shift+Z 撤销 / 重做
  - 空格 播放
  - ← → 切换上一句 / 下一句
  - Delete 删除选中的那一行
  - Ctrl+↑ / Ctrl+↓ 切换上一场 / 下一场
  - Ctrl+O 打开项目
  - Ctrl+I 导入素材
  - Ctrl+E 导出
  - 框选修图窗口里：Esc 关闭
- 数据存放：游戏文件夹下的 `_studio\`。
  - `backup\`：每次保存或替换之前的备份。
  - `inbox\`：导入的素材。
  - `export\`：导出的游戏包，会包含 `img\l\` 子文件夹。
  - `state.json`：哪些台词配音需要重录。
- 源代码在仓库根目录（package.json、main.js、core.js、renderer/）。开发时运行 `npm install`，再运行 `npm start`；打 Windows 包运行 `npm run dist:win`。注意：`moban_art\yingyou-studio\` 里的还是 v0.2 的旧代码，v0.3、v0.4 的改动目前只在 `影游剪辑台\resources\app\` 里。

## 路线图
- 审图改图：
  - 框选修图里加「不用 AI」的快速处理：区域虚化、加光晕、用周围颜色盖掉文字（免费、几秒完成）。
  - 道具参考图（第四套人民币、无字顶灯、打开的黑皮箱、夏利车头），从源头减少细节错误。
