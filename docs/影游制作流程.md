## 一句话原则

**越往上游修越便宜。** 参考图错了，后面全错；提示词错了，出图必错；图片版没定稿就做视频，返工最贵。所以每一步都有一道关，过了关才进下一步。人工发现的问题，先判断它属于哪一步，回到那一步修，不在下游硬改。

## 人机协同：人是流程里的信息源，不只是最后的审批人（2026-11-01 讨论）

**问题**：前一版流程写得像一条自动化流水线，人只在几道「关」上出现，也没写清每一步到底谁说了算。

**判断**：AI 能自己迭代变好，前提是有可靠的反馈信号。数学证明有检查器，代码有测试，对错不需要人。我们的场景没有这样的信号，AI 只能拿替代信号去优化，替代信号会和真正的目标慢慢偏开；反馈错了，它越努力偏得越远。所以在不能构造可靠反馈的地方，要由人提供反馈，人机协同完成。

《末班客》里的证据：
- AI 质检判「通过」，座位其实画错了；
- 自动修图把分数改高了，却把原本画对的地方改坏了；
- 质检模型自己把左舵判成了右舵；
- 提示词里的矛盾，连续几轮重画都没被发现，直到人去审才看出来。

### 反馈分三层

| 层 | 例子 | 怎么用 |
|---|---|---|
| 1. 机器能验证 | 框外像素有没有变、文件在不在、参考图是否超过 5 张、「画面里」和构图里的人对不对得上 | 完全交给程序，结果可信 |
| 2. 机器能感知，但只是近似 | AI 看图质检、人脸相似度打分 | 用来筛选和排序，不当最终裁判；定期拿人的判断校准（例如：AI 判通过的图里，人也认可的比例） |
| 3. 只能人定 | 这场戏要什么感觉；皮箱放在哪；大军还戴不戴帽子 | 不是判断对错，而是决定目标本身。目标是人的，AI 不能替人定 |

### 人也是信息源

1998 年加格达奇的出租车什么样、第四套人民币长什么样、东北话怎么说才地道，这些模型知识里要么模糊要么缺失，只有人能补进来。参考图审阅、统一设定，本质上是人往系统里注入真实世界的信息。

### 人的注意力要花在刀刃上，并且沉淀下来

- **放在上游**：审一次提示词，胜过审十张图。
- **AI 不确定时主动问，不自己拍板。** 例：推送代码时 AI 自作主张把许可证从「不开放」改成了 MIT，事情很小，但正属于该由人决定的那一类。
- **每次人的判断，尽量变成可复用的东西**：能写成规则的写成规则（进提示词检查或质检）；不能写成规则的，记进「创作决定记录」，下次不用再问一遍。

### 接下来要改的（待做）

- 流程每一步标明**谁来判断**：机器自动 / AI 提议、人确认 / 只能人定。
- 建一份**创作决定记录**：皮箱位置、帽子、手套这类决定，连同理由和日期。
- 统计 **AI 和人意见不一致**的地方（AI 通过但人打回、AI 打回但人通过），用来校准出图质检和视频质检。
- skill（`yingyou-flow`）按同样原则更新：遇到第 3 层的问题必须停下来问人。

## 各步骤

| 步骤 | 做什么 | 怎么做（工具） | 过关条件 | 约多少钱 |
|---|---|---|---|---|
| ⓪ 设定和参考图 | 定统一设定（年代、车、座位、人物、道具、光线、风格）；做齐参考图（人物、道具、场景） | 统一设定在 `storyboard\shotlist.json` 的 bible；参考图登记在 `refs\refs.json`；剪辑台「审阅 → ⓪ 参考图」：看图、对照设定、改描述重新生成、新增 | 每张参考图人工过一遍；提示词里提到的东西都有参考图（提示词检查不再提示「参考图库里还没有」） | 每张约 $0.14 |
| ① 分镜表和提示词 | 每句台词一条：景别、画面里有谁、构图（按画面方向写左右和机位）、画面描述、参考图（最多 5 张） | 剪辑台「审阅 → ① 提示词」：看实际发给模型的完整提示词、自动检查、直接改字段 | 每条人工过一遍；自动检查没有红色矛盾 | 免费 |
| ② 构图（难镜头） | 车内、左右关系、多人、机位朝后的镜头，先画构图图和俯视位置图 | `storyboard\sketch\<镜头>.png` 和 `_map.png`（Claude 画 SVG / 简笔，或 GPT、Gemini 写 SVG）；登记到分镜表的 sketch 字段 | 构图图和分镜表一致（谁在左谁在右、车头朝向、左舵） | 免费～几毛 |
| ③ 出图 + AI 质检 + 自动修 | 按分镜表出图；AI 对照分镜、参考图和构图图质检；不通过的重画或局部修改 | 剪辑台故事板「给缺图的句子出图」「整场检查并自动修」（`batch.py`、`refine.py`） | AI 质检通过，或标「需人看」交给下一步 | 每张约 $0.14～0.5 |
| ④ 图片审阅 | 人一张张看图：通过 / 有问题 / 修图 / 重画 / 换成之前的候选 | 剪辑台「审阅 → ② 图片」；细节问题用「框选修图」：形状不变选「只改样子」，要加东西选「要加东西或改形状」 | 每张图人工通过（AI 通过的也要看） | 修图每次约 $0.14 |
| ⑤ 图片版试玩 | 整局玩一遍，查剧情、线索、节奏、选择、画面衔接 | 剪辑台「审阅 → 剧本」（自动查走不到、死路、线索拿不到）；「预览」；AI 试玩（`gpt_test\`）；真人试玩 | 剧本审阅没有红色问题；剧情和画面定稿 | 低 |
| ⑥ 按需做视频 | 只把需要动的镜头做成视频（关键动作、要对口型的台词、建立镜头），用定稿图当首帧。先出草稿在游戏里过一遍，再花钱生成 | 剪辑台「审阅 → ③ 草稿」：AI 写视频提示词、按剧本算时长、代码草稿（免费）/ AI 尾帧 / 2.5D / 本地模型，手绘动作；「④ 成片」选模型生成（海螺 / H3，`autofix.py`） | 视频提示词人审过（第一次生成前必须）；草稿版整局过一遍 | 草稿免费～$0.14；正式每条约 ¥1.3～5 |
| ⑦ 视频审阅 | 机器检查 + AI 质检 + 自动重拍；口型同步；人工看标记的 | 剪辑台「④ 成片」：候选对比、本地替换、剪辑点、原声；`qc\run_qc.bat`、`autofix\lipsync.py` | 每条成片人工确认；只差口型的标「等口型同步」 | — |
| ⑧ 声音 | 配音、音效、环境声；声音质检 | 剪辑台「⓪ 参考 → 声音音色」复刻角色音色、「⑤ 台词」核对和补配音；ElevenLabs 音效；`qc\run_qc_audio.bat` | 「⑤ 台词」没有缺失和改字待更新；逐字对上剧本，响度统一 | 复刻和配音按 MiniMax 计费 |
| ⑨ 导出 | 素材检查后导出游戏包 | 剪辑台「素材检查」「导出游戏」 | 素材检查没有红色问题 | — |

## 反馈闭环：发现问题以后怎么办

人工审阅、试玩、AI 质检发现的每个问题，先归类，再回到对应的那一步修：

| 问题像什么 | 属于哪一步 | 怎么修 |
|---|---|---|
| 车型、人物长相、道具样子不对，而且好几张图都错 | ⓪ 参考图 | 重新生成或换参考图；补统一设定 |
| 画出了参考图里没有的东西，年代、样子不对（钞票、BP机、保险单） | ⓪ 参考图 | 新增参考图，附到相关镜头 |
| 多了一个人、座位错、和台词对不上；同一个错重画几次都出现 | ① 提示词 | 改分镜字段（「画面里」和构图要一致；关键要求不要只写在备注里） |
| 左右反了、机位方向错、车头朝向错 | ② 构图 | 画或改构图图、俯视位置图 |
| 局部细节：颜色、文字、多一只手、道具小错 | ④ 修图 | 框选修图（只改样子） |
| 要在画面里加东西、改形状 | ④ 修图 | 框选修图（要加东西或改形状） |
| 剧情、线索、节奏问题 | ⑤ 剧本 | 改剧本，再回到 ① 补或改分镜 |
| 视频里人物不张嘴 | ⑦ 口型同步 | 重拍解决不了，做口型同步 |

**每次发现一种新问题，就把它写成规则**，以后在更上游自动拦住：
- 能在提示词里看出来的（字段矛盾、方向词、缺参考图）：加进剪辑台的提示词自动检查；
- 只能看图看出来的（年代穿帮、左右舵、换脸）：加进出图质检和视频质检的检查项（`batch.py` 的质检提示、`qc\specs.json` 的全局规则）；
- 所有图都要遵守的：加进统一设定。

## 踩坑规则表（已经写进检查的）

| 问题 | 在哪拦住 |
|---|---|
| 出租车必须左舵；从车里往前看司机在画面左，从车头前方往里看在右 | 提示词检查、出图质检、视频质检 |
| 夏利是五门两厢（掀背），不要写「后备箱」 | 提示词检查（统一设定待补「两厢」） |
| 1998 年只有第四套人民币，没有粉红色百元钞 | 统一设定、出图和视频质检；建议补「第四套人民币」参考图 |
| 从后座往前拍，司机一定入画；机位朝后看不到后视镜和红穗子 | 提示词检查 |
| 构图或描述里出现的人，「画面里」要写上（只露手、背影也要写明） | 提示词检查 |
| 分镜表的「备注」不会发给模型 | 提示词检查 |
| 台词说看指甲，手不能戴手套 | 提示词检查 |
| 画面里不能有文字、水印（车顶灯常冒出 TAXI） | 统一设定、出图质检 |
| 同一段视频里不能换脸；检查站背景不能有城市楼房 | 视频质检 |
| 改写的提示词里不能有血、伤痕、抢劫等敏感词 | `sanitize.py` |
| 局部修改会顺手改坏别处 | 框选修图：只改样子时框外一个像素不变 |
| 已经通过的图，不要再被「自动修」改坏 | `refine.py` 默认只处理没通过的 |
| 视频提示词没人看过就花钱生成 | `autofix.py` 第一次生成前检查 `vprompt:` 审阅记录（方案 C，2026-11-01） |
| 进场第一句就有自己的分镜图，场景视频根本播不到 | `durations.py` 标「游戏里用不上」，草稿和生成都跳过（2026-11-02） |
| 声音复刻结果不确定时重复提交、重复扣费 | 声音服务记「待核实」，不自动重试（v0.6） |
| 台词改了字，配音还是旧的 | 「⑤ 台词」标「改字待更新」 |

## 每一轮优化怎么跑（例行检查清单）

1. 打开剪辑台，看顶栏「审阅」上的待审数。
2. 剧本：有红色问题（走不到、死路、线索拿不到）的先改；改过的场景顺着「下游要复查」往下看。
3. ⓪ 参考图：有待审或缺图的先处理。
4. ① 提示词：先清掉红色矛盾，再一条条确认；黄色提醒里的「＋ 新增参考图」「附上」顺手处理；跑一次「检查衔接」。
5. ② 构图：新出现的难镜头补构图图（可以手绘，再让 AI 整理）。
6. ③ 出图：故事板「给缺图的句子出图」；有没通过的跑「整场检查并自动修」。出图前如果有没审过的提示词，剪辑台会提醒。
7. ④ 图片审阅：一张张过，细节用框选修图。
8. ⑤ 整局试玩，记录问题，按上面的「反馈闭环」归类。
9. 新问题写成规则，更新这份文档的「踩坑规则表」。
10. 图片版定稿的部分，才进入 ⑥～⑨：先在「③ 草稿」出免费草稿、整局过一遍，再到「④ 成片」花钱生成；最后在「⑤ 台词」把配音补齐。

注意：这份文档的步骤编号（⓪～⑨）和剪辑台审阅页的编号（⓪ 参考、① 提示词、② 图片、③ 草稿、④ 成片、⑤ 台词）不是一一对应的，按名称对照。

## 让 AI 按流程做

这套流程也写成了 skill（`yingyou-flow`）。在 Claude 或 Codex 里说「按影游流程过一遍 xx 场景」「审一下 xx 的提示词」「这张图有问题，帮我归类并修」，它会按同样的步骤、文件和规则来做。
